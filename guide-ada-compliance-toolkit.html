What Is ADA Website Compliance?

The Americans with Disabilities Act (ADA) requires that public accommodations be accessible to people with disabilities. Courts have consistently ruled that websites count as public accommodations. The compliance standard is WCAG 2.1 Level AA — a set of 78 success criteria covering:

  • Perceivable: Content must be presentable in ways users can perceive
  • Operable: Interface components must be operable by all users
  • Understandable: Content and operation must be understandable
  • Robust: Content must work with assistive technologies
